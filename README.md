# bullet-and-hell

Jogo de sobrevivência com armas automáticas, inspirado em Vampire Survivors. Você se move, inimigos vêm em ondas crescentes e cada gema de XP aproxima você da próxima melhoria.

## Como rodar

Não há dependências nem build. Sirva a pasta com qualquer servidor estático:

```
python3 -m http.server 8000
```

Depois acesse http://localhost:8000.

## Controles

- `W A S D` ou setas: mover
- `Enter`: reiniciar após a derrota
